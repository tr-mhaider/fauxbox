# @fauxbox/ui

Shared design system for the whole Fauxbox app package: color tokens (light and
dark), typography, spacing, and the component primitives used by the dashboard
and, later, the control-plane UI.

This package is a placeholder created in Phase 0. It is filled in Phase 8
(design system and Next.js foundation): tokens as CSS variables plus a headless,
themeable component layer (Tailwind + Radix/shadcn-style primitives).
